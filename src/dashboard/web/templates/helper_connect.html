Connect an AI assistant

Some AI assistant apps can use a helper through a small connector that comes with Dashboard Plus (it uses a standard called MCP). Paste these settings where your assistant's app lists its MCP servers, then replace YOUR-KEY-HERE with the helper's key.

{{ assistant }}

The key is a password. Your assistant's app keeps these settings in a file on this computer, so anyone who can open that file can use the key. Don't paste the key into a chat.

If the assistant is an online service, that service will see what the helper reads. Anything it suggests still waits for you on the Review page.

The address changes each time Dashboard opens: update it in the assistant's settings after reopening. To disconnect, turn the helper's access off here and remove the "dashboard-plus" lines from the assistant's settings.
