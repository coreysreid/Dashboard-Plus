# Dashboard Plus

A free, portable, local-first "CRM for a home". A household records what it
cares about (pets, a wine cellar, projects, costs), sees it in charts, and gets
gentle questions that help it understand *why* numbers change.

**Status: planning.** No application code exists yet. Start with the documents
in `docs/`:

- [`docs/VISION.md`](docs/VISION.md): what this is, who it is for, what it will never be
- [`docs/CORE.md`](docs/CORE.md): the one-page v1 promise
- [`docs/DESIGN.md`](docs/DESIGN.md): how it will be built

Everything stays on your own computer. Nothing is sent anywhere unless you
switch on an optional outside source.
