# Mac preview: household read-through — 21 November 2026

Read `README.md` “On a Mac” and the short read-me generated by `tools/build_macos.py` as a first-time household tester. Compared both with decision 0096 and the CI build job. This is a **read-through, not a Mac run**. The only automated device evidence is GitHub's Apple silicon runner starting the app from its build folder; no person has opened a downloaded, quarantined copy on a real Mac yet. The recommendations below change words and test instructions, not shipped code.

The short bundled read-me should point to the main README or repeat the processor and two-ZIP guidance; it currently starts at “drag the app,” although that file is inside the inner ZIP. Neither document should call the preview a signed Mac release. The current “preview” and Apple silicon limits are correctly stated.

## What only a real Mac test can confirm

User 1 should use **invented records in a fresh Mac account or disposable test Mac**, not real household data, and record the macOS version and chip. This ordered check is still outstanding:

1. Sign in to GitHub, find the current green **main** run and download both nested ZIPs. Confirm the artifact name and Finder's extracted app name actually match the instructions. CI builds the artifact but does not test this download path.
2. Drag the extracted app to Applications and open it from there. Record the exact Gatekeeper warning, **Done**, **Open Anyway**, authentication and any second warning. Do not disable Mac security features. CI starts from the build folder without downloaded-file quarantine.
3. Confirm the browser opens to setup, and **Save and exit** reaches **Saved and closed**. Close only the browser tab, reopen the app and confirm it brings the same page back. A launch failure alert and a slow start have not been seen on a real Mac.
4. Add one invented Stock item, close, reopen and confirm it remains. Replace the app with a later preview and check the same item remains. Confirm its data folder is in Application Support, separate from the app, without moving or deleting it.
5. Locate the second backup copy, test the visible backup status, and note whether the hidden `~/.local/share/dashboard-plus/backups` path is understandable. CI smoke checks the default data folder but does not stand in for a household backup or update.
6. Check the lack of app icon, Dock icon and Quit menu against what a household expects. An Intel Mac remains untested and has no preview artifact; do not infer compatibility from the Apple silicon job.
