# Core work for a household grab list

Checked 17 November 2026. The exact table targets are shipped `people.people`, `pets.pets` and `stock.items`, and draft `medical.kits`, `documents.documents` and `home_layout.places`. Documents currently stores a free-text `place`; the core cannot show it as a shared full path without a reviewed migration. Existing sheets declare fixed table sections, but this sheet needs ordered rows, carrier links, per-row print privacy, a preview and a one-page-or-continue layout. There is no generic cross-module list table or checked/reviewed state yet.

Lane A needs a plan and row model with optional typed links to several modules, a required household-authored `name`, a carrier People link, a reviewed place link or text, group/order, `take_first`, print-location consent, and a last-reviewed date. The picker must handle missing modules and deleted links. Refresh suggested values after source changes but protect fields a person edited. Add a print formatter that renders full paths, handles blank/missing values and keeps private notes and IDs off the ordinary sheet. A manual printable fallback should remain available when no optional module is on. The new shared Home layout place migration must preserve Medical, Documents and Stock links before the sheet can trust a path.

This draft gives no instruction to leave or stay. Its only external content sources are [NZ Get Ready's household-plan page](https://getready.govt.nz/prepared/household/make-a-plan) and [US CDC personal needs](https://www.cdc.gov/prepare-your-health/take-action/personal-needs.html), checked 17 November 2026. They explain why household plans and personal needs are worth considering, not the completeness of these synthetic rows.
