# One-page grab list: print layout

Target one A4 or US Letter page at ordinary print scale; test both, including a long but realistic list. At the top: **“Grab list for [household]”**, **Reviewed [local date]**, **Printed [local date and time]**. Beneath: “Follow current local instructions. This is the list your household wrote.” Do not print a universal evacuation instruction or an automatic “ready” badge.

| ✓ | What to take | Where to find it | Who carries it |
|---|---|---|---|
| ☐ | **Take first:** Apartment first aid kit | Hallway › Hall closet | Maria Garcia |
| ☐ | Luna and carrier | Main bedroom › Under the bed | Carlos Garcia |
| ☐ | Apartment insurance policy | Location hidden on this copy | Maria Garcia |

The sample rows are invented; [example.toml](example.toml) has the links. Show the household's chosen **Take first** rows, then the remaining groups with ruled checkboxes. Use clear headings and enough writing space for a handwritten update. If more rows cannot fit legibly, print “Continued on page 2” and a second page rather than shrinking below readable type; the one-page target is not a reason to omit a row. Show **“3 rows need a place or carrier”** near the top when applicable. A blank or deleted linked place prints “Check location” rather than a guessed path.

Default print mode excludes People sensitive details, Medical check notes, document numbers, account identifiers, secret storage instructions and private row notes. Documents' text location is hidden by default, and the preview says what will be exposed if **Include private locations on this copy** is chosen. A person can still print an ordinary list with document titles and “Location hidden on this copy.” Never put private details in the browser page title or print URL. Link to a source or local authority only if the household chose one; a printed web link is not an offline warning service.

The sheet is not the emergency sheet, which carries contacts. It complements that sheet; it should not duplicate private medical details. The print preview shows the exact same rows, order and privacy choices that will be printed. Footer: “Check this list after a move, a new household member or a changed plan.”
