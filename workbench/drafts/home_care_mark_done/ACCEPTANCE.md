# Acceptance checks for Home care Mark done

Use temporary invented Smith, Garcia and Taylor households. These checks describe the future action; they are **not** claims about shipped code. Checked against the shipped Home care schema and DESIGN §5.8 on **19 November 2026**.

1. **Entry:** Each live Home care job offers Mark done. Opening the form, changing fields and cancelling creates no Work done row, job change, audit completion or new reminder.
2. **One save:** Saving Smith's gutters job adds exactly one linked Work done row, sets Last done to the entered Done on and sets Do again by to the chosen date. History identifies that one completion, and the confirmation names both dates.
3. **Actual person:** Who did it starts blank even when Who usually does it is set. Choosing John saves John on Work done without changing the job's usual person; leaving it blank saves no guessed person.
4. **Deliberate next date:** No next-date choice is preselected. Missing choice and a selected **Choose a date** with no date get a field error and no write. **No date yet** clears an old due date and removes its Needs attention reminder after Save.
5. **Repeat offer:** A job with no repeat offers no calculated date. Choosing “Every 3 months” on Smith's job offers 19/02/27 from Done on 19/11/26; changing Done on updates the offer. The offer is not saved until selected and confirmed. A manually chosen date overrides this completion only; the repeat rule stays.
6. **Calendar edges:** 31/01/27 + one month offers 28/02/27; 31/01/28 offers 29/02/28; 29/02/28 + one year offers 28/02/29; December + one month rolls into January. Weeks add seven calendar days each. No time-of-day or timezone shift changes a date-only result.
7. **Date order:** AU/UK/NZ type and see `20/05/27`; US types and sees `05/20/27`. Wrong-order and impossible dates get the shipped format/error wording; a next date before Done on is refused; the same day is permitted. Done on after the household's today is refused.
8. **Older work:** A Done on before the current Last done is refused by Mark done with a link to Add Work done. Adding an older Work done row by that existing path still leaves the job dates alone.
9. **Reminders and sheet:** Before Save, Needs attention and the Home care sheet show old dates. After Save, both show the new current dates; No date yet gives no due reminder. Work done notes and the actual-person field do not appear on the sheet, whose columns remain the current job summary.
10. **Retry:** Double-click Save and resend the same form body, including after a connection retry. Both return the same completion; there is one Work done row, one job date change and one completion history event.
11. **Stale form:** Open two forms, save one, then submit the other with different dates. The second is refused with the exact stale message; it neither changes the job nor adds Work done. A person edit to the job while the form is open has the same result.
12. **Bad link or deletion:** An invalid Who did it, deleted person, deleted job or switched-off Home care module cannot leave a partial Work done row or a changed job. Restoring the job or a backup does not replay Mark done.
13. **Same-day duplicate:** A fresh form after a completion on that date warns rather than silently adding the same event. The person can use the separate Work done history form if a second note really belongs on that day.
14. **Undo succeeds:** Immediately Undo Smith's latest completion. The operation soft-deletes only its Work done row and restores the exact previous Last done and Do again by; the old reminder returns. The original completion and Undo remain in audit.
15. **Undo refuses conflict:** Edit either the job or its Work done entry, or save a later completion, then try old Undo. It refuses with the exact conflict message and makes no change. A second click of a successful Undo cannot reverse unrelated work.
16. **Invented examples and privacy:** Garcia can enter a US-order next date manually; Taylor can choose No date yet. Notes warn against codes and follow the shipped ordinary-field behavior. No alarm or extinguisher date is copied out of Home layout, and no schedule is presented as official advice.
