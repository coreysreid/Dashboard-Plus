# What Lane A needs from the core

Checked 17 November 2026. The shipped backup service makes `.db` copies, verifies SQLite integrity and records last-copy status. It has no backup catalogue, preview, folder restore/switch/undo, or export service. A record's **Restore it** button is a separate soft-delete operation and must not be confused with restoring a household backup.

For the household flow in FLOW.md, the core needs:

1. A read-only catalogue across the data-folder and optional computer-side backup directory, keyed by copy identity and location. Keep metadata (origin, kind, created time, household/folder identity, schema/app version, integrity result, attachments manifest) with each copy. The current `status.json` only describes the last attempt and `latest()` only searches the data folder; filename and file modification time cannot reliably prove identity or completeness after copying to another drive.
2. A safe preview that opens a candidate read-only, checks integrity and required tables, reports counts and version compatibility, and never runs migrations against the only copy. Show older/newer schema differences before offering a switch. Refuse a copy with unknown or incompatible schema until a supported path exists.
3. A restore transaction across *folders*, not just a database file: stage in a new destination, verify, and atomically mark ready. Back up the current folder before switching; persist a switch journal with both paths and snapshot IDs so Undo survives app restart. Handle removable-drive absence, short writes and two sequential switches. Never silently overwrite a folder.
4. An export reader that snapshots a consistent point in time and enumerates every installed table, annotations, notes and attachments under a manifest. The current backups contain the SQLite database only; attachment inclusion must be designed and tested before the preview promises it. Read labels and links from the module schema, preserve keys and IDs, render full place paths, and include deletion/audit history according to an explicit documented rule. Generate CSVs for ordinary spreadsheet use and test formula-injection handling in Excel and Sheets. Do not export `data/secrets/`.
5. A UI route for Backups and export, preview, new-folder destination, comparison, switch/undo, and export progress/result. Expose errors in plain language and keep the current dataset active on failure. Use the household's date display setting, with time zone, but keep machine-readable ISO dates in the export.

Do not implement a UI-only copy of `dashboard.db`: it would skip future attachments and cannot provide a reliable undo journal. The folder bundle format and migration policy need a Lane A decision before this draft becomes a household feature.
