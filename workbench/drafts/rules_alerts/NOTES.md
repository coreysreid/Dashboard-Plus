# Core gaps before a household rule can work

Checked **28 November 2026**. [PLAN.md](PLAN.md) is a proposed first rule and later boundaries. The current `watch` system handles present Stock minimums and declared due dates; it has no household rule builder, versioned rule store, eligible-measure registry, condition episodes, dismissal, quiet hours or notification channel. Pets weigh-ins has actual dated kg records, but nothing today confirms that two points show a clinical problem. Keep the 10% worked example as a fictional household choice, never a default or health recommendation.

The core needs an allowlisted rule declaration tied to an exact source table, subject global ID, dated numeric column and unit; validated threshold/window choices; a deterministic pair-selection policy shown to the person; accepted-row and correction/Undo evaluation; one condition episode with evidence revisions; neutral waiting, paused and retracted states; and source links that survive delete/restore or become safely unavailable. Re-evaluation must be idempotent and bounded as history grows. Link to Stock's existing **Keep at least** and declared due reminders rather than generating duplicates.

The first version has no outgoing notification and no Quiet hours control. If a channel is added later, use the household time zone, an off-by-default opt-in, no bypass of quiet hours, and a delayed-delivery policy. Needs attention remains readable when opened. Never turn no entry into a missed event, food put out into food eaten, or two weigh-ins into a diagnosis. Future sources need their own completeness and plausibility gates before entering the builder.

Rule configuration and derived cards need their own decision 0140 sharing policy. A member cannot infer a source kept on main through an alert or a stale copy. Private sources stay behind their existing Show gate on screen and in print, with a separate neutral rule card. No helper read or write of rules in version one. No free-form rule title in version one; any later text must pass the 0141 forbidden-detail guard. The draft does not edit shipped code or assert medical guidance.
