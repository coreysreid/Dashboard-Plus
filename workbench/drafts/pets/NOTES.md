# Pets draft notes

This files-only draft records pets, weigh-ins, food, medication given and vet visits. Owner and vet link to People. It uses invented examples only.

Open questions for Lane A: should food amounts always use grams, or support other units? How should a household record a course of medicine or a missed dose? The design also mentions walks and litter logs; this compact draft does not include them yet.

Core features needed for the full vision: a daily-facts view that totals food per pet and day, charts and the question loop. Those are later milestones and are not declared here. A reminder for scheduled medication would also need core support.
