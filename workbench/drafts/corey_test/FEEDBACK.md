# What happened in your hour?

Keep this short. **Do not paste real names, phone numbers, addresses, account numbers, medical details, or screenshots containing them.** “Alex Example” and the other demo records are fine.

1. Did you finish setup and reach Home? **Yes / No**. If no, where did you stop?
2. How many of the twenty demo Stock items did you finish in the 20-minute stocktake? **___ / 20**. About how many minutes did it take?
3. Which step took the most effort or made you hesitate? Write the screen and the words you saw.
4. Did any date, quantity, place or drinking-water result differ from what you expected? Give the demo item and the two values.
5. Could you find the first aid kit, Pip and Alex again? **All / Some / None**. What was hard to find?
6. Did the Emergency sheet show what you wanted, and did it show anything you did not expect?
7. Did **Save and exit** feel complete? **Yes / No / Unsure**. What did the last screen say?
8. What is the one change you would most want before using this for your real household?

## Paste a finding into `docs/BACKLOG.md`

For each distinct problem, copy **one row** into the top of the **Open** table in `docs/BACKLOG.md`, directly below its header. Replace the bracketed text; omit private details. The **Plan** cell can say “Lane A to reproduce” until the fix is known. Use a screen name and the exact visible words where possible.

```markdown
| 2026-11-17 | (Corey one-hour test, task [number]) I [what I did with demo data]. I expected [what I expected]. The screen said/showed “[exact words]” and [what happened]. | Lane A to reproduce; [suggested change, if any]. |
```

If a task worked well, add a short note under the row instead of a false bug report. If a problem stopped the session, put its row first and mention the task number. This is a copy-and-paste form; it does not automatically write to the repository.
