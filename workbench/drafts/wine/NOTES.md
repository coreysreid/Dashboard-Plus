# Wine collection draft notes

This compact files-only draft tracks wines, bottle counts and tasting notes. It is meant to show how little a useful module needs.

Open questions for Lane A: should bottle purchases and openings be separate movements, so the quantity cannot drift? Should price have a currency setting? Is a place link to Stock useful, or would it make this small module too dependent on Stock?

Core features needed for the fuller vision: a stock-movement action and, later, optional charts. No outside source or custom code is needed for this draft.
