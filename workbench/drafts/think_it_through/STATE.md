# How a practice run is saved

Designed **21 November 2026** against decision 0104. This is a design, not a shipped screen or a modification to the 49 current questions.

Each drill has a stable `scenario_id`, version, title, applicability (`country`, region/hazard/home type where relevant), a source key from [SOURCES.md](SOURCES.md), and an ordered list of step IDs. Each step has original `question`, a record selector, a precise missing-record sentence, and an optional `write_in` destination. A record is an **offer to inspect**, never an automatic Yes. Link by permanent ID and revision; if moved, deleted, private or switched off, show a neutral changed/missing state and ask again. Do not copy a private record value into an answer or a log.

For each practice run save: scenario ID/version; household-local **Practised on** date; person-entered answers per step (**I have a plan**, **I need to check**, **Not relevant to my household**, plus optional short own words); any record ID deliberately chosen; and **Look again on** date chosen by the household. Keep earlier runs in history, never overwrite them. The app may offer a 12-month look-again date as an editorial suggestion, explicitly **not an official deadline**. A changed source record brings the step back for review, but never marks the whole household unsafe or prepared. Completing a drill means someone walked through it, not that the plan was verified. **Not now** saves no practice run.

Decision 0104's `readiness__answers` holds one Yes/Not yet/Not relevant answer per existing prompt and ordinary notes that travel. It cannot hold a multi-step run or private narrative. Reuse an existing prompt ID where the wording, match and answer truly match; a scenario-only question can be a new prompt under 0104's proposed `[[scenario]]` shape. Store the run date and per-step answer in a new `readiness__drill_runs`/`drill_steps` contract with history and explicit privacy. Free-text answers about occupants, security or medicine should be **sensitive, `travels = "never"`** and absent from helper read, general export, Home preview and notification. The practice date, scenario ID and review date may travel, but a member must not interpret a missing local answer as a blank to overwrite. A person can deliberately record a broad nonprivate Yes/Not yet in Readiness separately. The assistant or helper may look at public source text, never answer a drill for the household.

Screen heading **Think it through**. Intro **These are short practice questions for a calm moment. They use records you chose to keep. They do not say your home is safe. If something is happening now, use local emergency instructions instead.** Each step shows **From your records** with a link, **You haven't recorded …** when absent, and **Your answer** with the choices. Finish button **Save this practice**; confirmation **Practised on 21/11/26 · Look again on [chosen date]**. The household can stop midway and save **Continue later** without marking it practised. A visible **Sources and local limits** link opens the relevant ledger entry.
