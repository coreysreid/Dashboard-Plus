# Core work before changing the look

Checked **27 November 2026**. [PLAN.md](PLAN.md) describes an original visual direction; it does not alter `src/`, modules or generated screenshots. The current UI already has semantic light/dark tokens, chart and calendar marks, a text alternative for each chart/calendar and forced-colours/print styles. Lane A needs current visual captures before choosing changes: the gallery has no chart or dark/print/high-contrast image, and the Garcia dose-calendar image predates decision 0142's private subject wording.

If the pictograms are adopted, the core needs a small local SVG set and one reusable decorative icon placement beside module text. No external icon font, remote image or dependency is needed. Link and heading names must remain complete without the icon; keyboard focus belongs to the full link. Keep status symbols separate from module pictograms. Each status needs its existing word, border/pattern and text list in all themes. The first implementation should touch Home area headings only, then be checked in live chart/calendar and sheet views before wider use.

Missing proof: measured colour contrast on actual light/dark surfaces; grayscale, Windows forced-colours, Mac increased-contrast, black/white A4 and Letter printing; chart and calendar screen-reader order; 320 px and large text on a real phone. No claim that the pictured text or colours are current should be made until `tools/make_screenshots.py` has regenerated them from the chosen commit. Decision 0142 already supersedes the old **Given to #4** image. A visual change to the shipped app needs Lane A's technical decision, implementation and checks; this workbench draft is not a workaround.
