# Ownership, sources and core gaps

Checked **21 November 2026**: shipped `modules/vehicles/`, People links, decisions 0058, 0089 and 0100, and the example households. All odometer values, providers and estimates here are invented. A vehicle's manual, service book, mechanic and written quote remain the source for actual maintenance dates, work and prices; this draft supplies no safety or servicing interval.

The draft sits **beside** Vehicles and links its existing vehicle and service IDs. It does not replace the authoritative `vehicles.services.next_due`, last-done date, insurance or registration reminder. Promotion could instead fold the two tables into Vehicles through a migration, preserving stable IDs and links. Core has no optional extension placement on a Vehicles detail page, so these rows currently appear as a separate module. It also cannot make a `watch.expiring` warning from a household-entered mileage target and the latest reading. Adding that target to the shipped service record, same-unit validation, stale-reading handling and cross-table warning would be separate core/module work.

`amount`, `scope` and `notes` are sensitive and `travels = "never"`. Readings, estimate existence/type/provider/date and service links are ordinary and may travel. A member therefore can have an estimate row without its price; the UI must label **Price and scope only on the computer where entered**. This privacy choice may make cross-device quote comparison incomplete; Corey must choose it explicitly before promotion. A private value in a helper-suggested estimate cannot pass through today's helper API. Do not add financial values to a record name, reminder or print sheet.

The schema accepts an amount without a unit only because household currency is a setting; display must name that currency. `datetime` still needs a durable instant/zone rule for phone members. A low reading, odometer replacement, rollover, different units and changed quote scope need manual confirmation. Add a complete print or export only after its privacy and pagination contract is decided; none is declared here.
