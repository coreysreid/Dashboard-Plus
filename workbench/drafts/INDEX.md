# workbench/drafts/  (summary: draft modules and content, one folder each, not switched on for anyone)
Each draft is a module folder (module.toml, tables.toml, labels.toml, migrations/)
or a content folder, with a NOTES.md listing open questions and the core features it
needs, and an example.toml with made-up rows for the three example households.
Add a row here for each draft folder you create.

| Entry | What it is | Open it when |
|---|---|---|
| catalogue/ | 800 common goods after round three, with water-count rules | reviewing stocktake choices |
| home_layout/ | Nested places, exits, shut-offs and an Our home sheet | reviewing home layout |
| stock_lots/ | Item lots (layered use-by dates), screen flows and core needs | planning layered stock dates |
| medical/ | First aid kits, kit checks and training, with due dates and a sheet | reviewing or promoting it |
| readiness/ | 49 source-linked "Have you thought about…?" questions | reviewing readiness prompts |
| country-packs/ | Sourced AU, US, UK and NZ content | reviewing country packs |
| documents/ | Where important papers are, with renewal dates | reviewing document records |
| home_care/ | Household checks and jobs with due-date history | reviewing home checks |
| wine/ | A compact wine collection module | reviewing or promoting it |
| collections/ | Hobby collection items, places, costs and household value estimates | reviewing or promoting it |
| vehicles/ | Vehicle reminders, roadside contacts and Stock car kits | reviewing or promoting it |
| guide/ | A plain first-use guide with screenshot links | helping new households |
