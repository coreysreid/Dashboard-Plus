# Home care draft

A household can keep a short list of smoke alarm checks, gutter care, water-heater work and other jobs. It can log each completion and enter the next date itself. The due-date watch uses “due”, not “expired”. No default maintenance interval is supplied: equipment, regulations and building conditions vary, so the household should use the relevant manual, provider or local authority. This draft is a record, not instructions for electrical, gas, fire or roof work.

A completed `work_done` record does **not** currently update `jobs.last_done` or `jobs.next_due`. A household must edit the job too. Lane A would need an atomic “Mark done” action that writes history and updates the current job, plus a recurrence rule chosen by the household and calculated from the right anchor date. The core's generic events recurrence does not yet update a module job or derive its next date; do not imply automatic repeats until that exists. When Home layout is promoted, replace the free-text place with a shared full-path link; coordinate smoke alarms with Home layout's equipment records so there is one source of truth for test and battery dates. The draft sheet is a snapshot of the current list, not a separate schedule or a promise of automatic repeats.
