# Reporting a security problem

Dashboard Plus keeps household information on the user's computer. Please report anything that could let another person read, change, erase or send that information without the household's choice. Examples include a way around the local sign-in link, a page that accepts requests from another website, an unsafe module or import, or a backup that exposes private records.

Please use [GitHub's private vulnerability report](https://github.com/coreysreid/Dashboard-Plus/security/advisories/new) if that option is available. If it is unavailable, open a public issue that asks the maintainer for a private reporting channel **without including the vulnerability details**. Do not put household data, tokens, private paths, a working exploit or screenshots containing personal information in a public issue or pull request. A small example using invented data is useful once there is a private channel.

Include what version or commit you tried, what happened, what you expected and the minimum steps needed to reproduce it. The maintainer can then confirm receipt, discuss the impact and arrange a fix before details are published. For a general bug with no security impact, use the bug report template instead.
